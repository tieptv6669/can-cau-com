Hợp âm **sus2 (suspended 2nd)** là một màu sắc rất hay trong hòa âm hiện đại. Nó tạo cảm giác **mở, thoáng, chưa hoàn toàn ổn định**, thường được dùng trong pop, rock, folk, worship, ballad và cả nhạc phim.

## 1. Cấu tạo của hợp âm sus2

Công thức:

**1 - 2 - 5**

Ví dụ:

* Csus2 = C - D - G
* Dsus2 = D - E - A
* Asus2 = A - B - E

So với hợp âm trưởng:

* C = C - E - G
* Csus2 = C - D - G

Ta thấy nốt **E (bậc 3)** bị thay bằng **D (bậc 2)**.

Chính vì thiếu bậc 3 nên sus2 không xác định rõ là trưởng hay thứ, tạo cảm giác "lửng lơ" rất đặc biệt.

---

## 2. Cách dùng sus2 như một hợp âm trang trí

Đây là cách phổ biến nhất.

Ví dụ trong giọng C:

```
C → Csus2 → C
```

Nốt:

```
C E G
C D G
C E G
```

Người nghe sẽ cảm thấy giai điệu chuyển động nhẹ nhàng bên trong hợp âm.

Ví dụ:

```
Am → Asus2 → Am
```

rất thường gặp trong các bản ballad.

---

## 3. Dùng sus2 để tạo chuyển động giữa các hợp âm

Ví dụ:

```
C → Csus2 → G
```

hoặc

```
G → Gsus2 → Em
```

Sus2 đóng vai trò như một cây cầu làm cho việc chuyển hợp âm mềm mại hơn.

---

## 4. Thay thế hợp âm trưởng

Nhiều khi bạn có thể thay hợp âm trưởng bằng sus2.

Ví dụ vòng:

```
C - G - Am - F
```

có thể biến thành:

```
Csus2 - Gsus2 - Am - Fmaj7
```

Âm thanh sẽ hiện đại hơn rất nhiều.

Đây là kỹ thuật rất phổ biến trong nhạc của John Mayer, Ed Sheeran và nhiều nghệ sĩ acoustic.

---

## 5. Dùng sus2 ở cuối câu nhạc

Nếu kết thúc bằng hợp âm trưởng thông thường:

```
| C |
```

nghe rất dứt khoát.

Nếu kết thúc bằng:

```
| Csus2 |
```

nghe sẽ có cảm giác:

* còn dư âm
* chưa khép lại hoàn toàn
* mở ra không gian

Rất phù hợp với nhạc phim hoặc những đoạn mang tính suy tư.

---

## 6. Kết hợp sus2 với add9

Đây là kỹ thuật nâng cao.

Ví dụ:

### Csus2

```
C D G
```

### Cadd9

```
C E G D
```

Khi hòa âm hiện đại, nhiều nhạc sĩ thường bắt đầu bằng sus2 rồi thêm bậc 3 vào:

```
Csus2 → Cadd9 → C
```

Âm thanh cực kỳ mượt.

---

## 7. Sus2 trong bass chuyển động

Ví dụ:

```
Dsus2/F#
```

Nốt:

```
Bass: F#
Hợp âm: D E A
```

Cách này thường dùng để tạo đường bass liền mạch:

```
G → Dsus2/F# → Em
```

Bass đi:

```
G → F# → E
```

Nghe rất chuyên nghiệp.

---

## 8. Một số vòng hòa âm sử dụng sus2 rất hay

### Vòng ballad

```
Csus2 - G - Am7 - Fmaj7
```

### Vòng acoustic

```
Dsus2 - A - Bm - G
```

### Vòng pop hiện đại

```
Gsus2 - D - Em7 - Cadd9
```

### Vòng nhạc phim

```
Asus2 - F#m7 - Dmaj7 - E
```

---

## 9. Nguyên tắc quan trọng nhất

Sus2 nghe hay nhất khi:

* Có giai điệu chứa bậc 2.
* Được giải quyết về hợp âm trưởng hoặc thứ.
* Dùng như màu sắc bổ sung thay vì lạm dụng mọi lúc.

Ví dụ rất đẹp:

```
Csus2 → C
Dsus2 → D
Asus2 → A
```

Người nghe sẽ cảm nhận được sự "căng nhẹ rồi thả lỏng".

Nếu ví hợp âm trưởng như một câu nói đã hoàn chỉnh, thì **sus2 giống như một câu nói đang được kéo dài thêm một chút trước khi kết thúc**, tạo cảm giác giàu cảm xúc và hiện đại hơn.
