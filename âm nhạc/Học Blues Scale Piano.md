Tuyệt vời! Nếu mục tiêu của bạn là **chơi Blues trên piano một cách tự do (improvise)** thì Blues Scale là thứ đầu tiên bạn nên thành thạo.

Tôi sẽ hướng dẫn theo lộ trình như một giáo viên piano, từ cơ bản đến ứng dụng.

---

# Bài 1: Blues Scale là gì?

Blues Scale là một thang âm được tạo ra từ **Minor Pentatonic Scale** và thêm vào một nốt đặc biệt gọi là **Blue Note**.

Công thức:

**1 - ♭3 - 4 - ♭5 - 5 - ♭7 - 1**

Ví dụ ở giọng C:

> **C - Eb - F - Gb - G - Bb - C**

Đây là Blues Scale phổ biến nhất.

---

# Vì sao Blues Scale nghe "bụi" và "da diết"?

Nốt **♭5 (Gb)** tạo nên cảm giác căng thẳng.

Đó chính là "Blue Note".

Ví dụ:

```
C → Eb → F → Gb → G
```

Khi đi từ

F → Gb → G

bạn sẽ nghe cảm giác rất "blues".

Nó giống như người ca sĩ đang "rên" hoặc "luyến".

# Ngón tay

Tay phải:

```
1 2 3 4 1 2 3

C Eb F Gb G Bb C
```

Hoặc

```
1 2 3 1 2 3 4
```

Không có quy tắc tuyệt đối.

Miễn sao chơi mượt.

---

# Bài tập 1

Chơi lên xuống:

```
C Eb F Gb G Bb C
C Bb G Gb F Eb C
```

Lặp lại 30 lần.

Không cần nhanh.

---

# Bài tập 2

Chỉ chơi Blue Note

```
F
Gb
G
```

Lặp:

```
F Gb G
F Gb G
F Gb G
```

Sau đó

```
G Gb F
```

Bạn sẽ bắt đầu nghe chất Blues.

# Bài tập 3

```

Eb F

F Gb

Gb G

G Bb

Bb C
```

Đây là cách tai quen với khoảng cách của Blues.

# Rhythm (quan trọng hơn nốt)

Blues không nằm ở nốt.

Blues nằm ở nhịp.

Ví dụ cùng một scale:

```
C Eb F Gb G Bb
```

Nếu chơi đều

```
♪ ♪ ♪ ♪ ♪ ♪
```

Nghe khá khô.

Nhưng nếu chơi

```
♫ ♪ ♩ ♪ ♫
```

Nghe ngay chất Blues.

---

# Swing Feel

Đừng chơi

```
1 & 2 & 3 &
```

Mà chơi

```
DA... da
DA... da
DA... da
```

Giống như

```
Long - Short

♪♩
♪♩
♪♩
```

Khoảng 90% Blues đều dùng kiểu này.

---

# Tay trái

Khi mới học chỉ cần đánh:

```
C

C

C

C
```

Hoặc

```
C + G
```

Hoặc

```
C7
```

Sau này mới học Walking Bass.

# Bí quyết của các nghệ sĩ Blues

Họ **không chơi nhiều nốt**, mà tập trung vào cách diễn đạt.

Ví dụ:

```
C

...

Eb

...

F Gb G

...

Bb

...

G
```

Khoảng lặng cũng là âm nhạc.

### Ngày 2

* Thuộc 3 pattern trên.
* Tập chậm với metronome ở 60 BPM.

### Ngày 3

* Chơi theo nhịp Swing.

### Ngày 4

* Improvise 5 phút chỉ với C Blues Scale.

* Chơi cùng backing track Blues 12 ô nhịp (12-bar blues) ở giọng C.

### Ngày 6

* Tập thêm các câu luyến (lick) ngắn.

### Ngày 7

* Ghi âm phần chơi của mình và nghe lại để nhận ra câu nào tạo cảm giác "blues" nhất.

## Lời khuyên quan trọng

Đừng cố học Blues Scale ở tất cả các tông ngay lập tức. Hãy **thành thạo C Blues Scale** trước: chơi không cần nhìn tay, cảm nhận được nhịp swing và tạo được những câu nhạc ngắn. Khi đã quen, việc chuyển sang G, D, F hay các tông khác sẽ nhanh hơn rất nhiều.

Ở bài tiếp theo, tôi có thể hướng dẫn bạn **12-Bar Blues trên piano** (vòng hợp âm nền của hầu hết các bản Blues) và cách ứng tấu bằng Blues Scale sao cho nghe giống một nghệ sĩ biểu diễn thực thụ.
